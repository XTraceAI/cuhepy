## Research hypothesis and concrete new candidate

Correctness benefits from a small target support, while exposed support and
public gadget relations can hurt privacy. The current known-prefix control
mixes those two dimensions. An experiment should **separate support cardinality,
unknown positions, source-annihilator structure and actual noise correlations**,
then couple them back to the paid precision/key/proof resources. A one-number
noise variance or declared ring size cannot do that.

Candidate: a small symbolic **dependency-aware gadget transcript compiler**
that takes registered key source labels/multipliers, masks, actual error atom
labels and target support policy. It emits a checkable source-annihilator basis,
public-mask rank, exact unwrapped error forms/Gram matrix and only justified
independent sample blocks. Its proposed joint frontier includes switching-digit
correctness, target support, setup/quota and precision; it must not certify
security from a Gaussian descriptor or silently publish hidden secret support.

The possible new contribution is a useful **joint resource/assurance rule or
algorithm** for reused derived-key graphs, with an explicit reduction interface
and complete cost effect. Source cancellation, HNF/LLL, covariance aggregation,
sparse secrets and generic transcript compilers are known. No originality has
been established; targeted closest work must precede the implementation.

## One bounded component at a time

1. **Primary comparison and new preregistration.** Read/cache the relevant
   full passages of HE security guidelines, sparse TFHE/secret-key controls,
   key-switching/circular-security and correlated-noise work. Compare the
   strongest general matrix/rank/noise compiler; review any existing auxiliary-
   key estimator treatment. Keep all hashes/versions. Specify the exact claimed
   difference; if a known complete method already supplies it, retain the
   useful adapter and stop that novelty claim before larger runs.
2. **Exact overlapping-row law.** For l rows with geometric g, all l-1 adjacent
   differences can have jointly uniform masks even though their errors overlap.
   Prove rank/surjectivity over the actual Q; enumerate the full tiny mask/coin
   law. Derive the tridiagonal covariance and the complete atom matrix F, not
   merely variances. Negacyclic positions, original S/S-squared cancellation and
   signed/omitted-level families stay explicit. Regress false IID row counting,
   wrong wrap/source labels, Q-dependent rank loss and noise-gap substitution.
   No cost tool receives correlated rows as IID.
3. **Modular versus integer annihilator discriminator.** Compare the E98
   disjoint adjacent basis to all-adjacent and short **mod-Q** source-null
   relations, including balanced-Q gadget digits and a strong standard integer-
   lattice normal-form/basis-reduction control. For each declared relation,
   test exact source cancellation, nonzero/uniform public mask, actual CBD
   atom law, support and cross-covariance. A small norm alone is not a modeled
   independent Gaussian attack; no actual key recovery or customer keys.
   Price setup/sample-count/noise-shape tradeoffs without a positive security
   conclusion. If exact laws require an unsupported correlated-noise estimator,
   record that gap instead of substituting an invented security cost.
4. **Hidden-support strong control.** Compare public prefix p with an honestly
   sampled full-ring target of hidden support cardinality h. Declare whether
   h, positive/negative counts or positions are public and the exact sampler.
   E97's fresh-coin law can use a support cap at any positions, but a hidden
   h-sparse target is not dimension h LWE. Prove this restricted correctness
   statement with independent integer controls; charge full N keys/ciphertexts,
   actual secret entropy/distribution, ROM/seed and reuse graph. Standard
   sparse-key methods get identical resources and full security caveats.
5. **Paid coupled frontier and R6.** Only use actual tool-compatible independent
   subsets and properly scoped primary reductions. Couple any support/gadget
   variant to all E97 source/sparse/dense/lifetime/precision points, key setup,
   target costs, verifier/PBS/original-binding and permitted-cache controls.
   Registered stop: known complete control contains the algorithm; no useful
   complete-cost difference; violated unknown-support/correlation law; or no
   justified candidate parameter family. Keep exact laws/negatives and return
   to the plan after each component. Do not activate Q6 on a favorable bound.

## Beyond this prerequisite: keep a concrete main-system route

The earlier E73 packed-query control already includes coefficient expansion,
seeded secret-key queries, pre-normalization and client/server verification
costs. SealPIR/Ali/Spiral/YPIR are strong controls, so another packed-query
upload ratio alone is not a new result. If parameters survive, the next
**separate** proposal should ask whether one dependency/carry-aware trace can
reduce a complete original-query-to-score verification relation or the total
paid expansion/contraction cost. Specify an actual new relation/algorithm,
aggregate shared noise atoms before squaring, and pay original query/index
binding. Do not reuse E73's unchecked server-expanded inputs or invent a
free plaintext/secret-error witness. Give a generic composed proof/compiler
the same intermediate commitments and reuse.

Three plausible research outcomes are kept distinct: a new joint assurance/
resource theorem; an original complete compact binding mechanism; or valuable
engineering/negative controls with no original mechanism. Selecting one must
pass mechanism gateB and useful-effect gateC. Initial project thresholds are
20% complete cost or2x binding-state/preparation with10% elapsed/traffic limits,
not venue requirements. Only then implement the full homemade protocol,
profile/native/CUDA, complete reduction/private lifecycle review, matched
larger BGV/Paillier/cache/network evidence and paper/artifact.
