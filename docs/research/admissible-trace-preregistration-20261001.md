# E81 preregistration: exact BGV under bounded noncanonical gadgets

E78 inventories9,142,272 canonical gadget coefficients on selected legacy
models. This identifies a candidate constraint interface, **not a measured
proof bottleneck**. Execute one finite correctness screen; no backend port or
proof-speed claim follows. Prior ring/range CKKS work already relaxes
decomposition and explicitly discusses BFV/BGV extensions. An adapter is not
the project's originality contribution.

Test the following conditional lemma. Owner-built switching keys satisfy
`b_j+a_j*s=B^j*s_target+t*e_j mod Q`, with certified `||e_j||inf<=eta`.
Admit any global integer digit polynomials with `0<=d_j<B` and
`sum B^j*d_j=c mod Q`, not necessarily the canonical representative. Then
switching phase is the intended phase plus `t*sum d_j*e_j mod Q`. Its
uniform norm bound is the existing canonical bound `t*N*ell*(B-1)*eta`.
Induct through every expansion branch and product; accept a profile only if
the full bound is strictly below Q/2. Original request/index/keys/all outputs
are still bound. No rescaling/modulus-switching relaxation is included.

Exhaust small scalar gadgets/secrets/key errors, including x+Q aliases. Run
actual homemade BGV packed queries at digit_bits5 (capacity exceeds Q enough
to exercise aliases) on all seven layouts. Compare canonical output and
several adversarial public alias choices: ciphertexts may differ but every
exact score/ID/top-3 must match. Bound-check/recompute before secret diagnostics.
Include unbounded carry/no-wrap failure and individually limb-valid but
globally incompatible RNS digit counterexamples. No modulus-Q-only assertion
counts as an exact-decoding proof without the uniform bound.

Count unchanged digit-box/recomposition/key/modulus/response costs and removed
canonical less-than-Q comparisons. Specialized prior proof controls may already
omit/share them. No proof bytes/time are inferred from comparison counts.
Retain only a scoped universal-correctness lemma/control, then return to R6.
