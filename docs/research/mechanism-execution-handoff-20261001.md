## Security and artifact boundary

Keep private challenge/seed-hint generation owner controlled. A local binding
hash does not authenticate a remotely provided private hint. Pin the original
request and all public context before verification. Check every supplied full-Q
relation before secret decryption; burn the shared lifetime on malformed,
rejected and replayed release. Fresh C1/seed reuse, carry/mod-t reduction,
server-selected expanded input, omitted C2/C1 and separately probeable proof
rounds have explicit negative controls. Durable epochs/rollback, timing,
related-secret/seeded HE assumptions and justified parameters remain open.
