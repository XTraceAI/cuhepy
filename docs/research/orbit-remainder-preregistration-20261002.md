## Candidate and exact falsifiers

For power-of-two B, successive power-of-two targets T_i >= 2, set
L_-1=B and L_i=L_(i-1)/T_i >= 2. Input x is canonical mod B; later
inputs are unreduced centered remainders. Use R_i in [-L_i/2,L_i/2),
U_i=(input-R_i)/L_i and H_i=1[input mod L_i=L_i/2].

For a negative signed mask rotation, predict

```
R_i' = -R_i - L_i H_i
U_0' = -U_0 + H_0 + T_0 * 1[x != 0]
U_i' = -U_i + H_i - T_i H_(i-1), i > 0.
```

Compare with an independently computed literal chain, complete public block
outputs and full integer phase decomposition under local toy secrets. Stop
an identity if it fails any finite input, endpoint, stage or rotation.
Modulo-only quotient reconstruction and omitted/false half bits are negatives.
No secret phase, noise or plaintext winner is a server witness.

## Rounded odd-source grid question

For odd Q and cumulative target A=prod T_i, L=B/A>=2, enumerate every x in
[0,Q) and count ties in round(B*x/Q) mod L. Check both the proposed no-tie
condition B>=A*Q and the sharper candidate count

`number_of_ties = 2*floor((Q+L)/(2L))`.

This candidate follows by enumerating odd integers y with |y|<Q/L in
`2*A*x-(2*j+1)*Q=y`; gcd(Q,2*A)=1. Verify an independent interval-count
oracle and all small cards. Treat the count as uniform-source arithmetic,
not a distribution claim for evaluated ciphertexts or a priority claim.
Check overlap of later-stage tie sets explicitly; they are not independently
resampled. Distinct dyadic half residues predict disjoint tie sets.
