## Exact relation and why it is complete

Owner inputs fix original query/index, public switching keys, layout and the
complete immutable plan with its trusted public Q/P bound replay. A compiler
builds a generic linear polynomial DAG over locally bound query polynomials,
query digits where seeds need them, and canonical source digits. Public index
and key polynomials are constants. Shared-subexpression normalization is a
standard generic control, not a new optimizer.

A canonical source witness is one immutable coefficient tuple in `[0,Q)`.
Extract its unique radix digits from that same integer. Each product source
is constrained to original `query_C1*index_C1`, so a false c2 cannot become a
trusted tensor merely by passing switching. Each canonical rotation source is
constrained to the virtual shifted/automorphed minus C1. Tensor C0/C1, all
relinearization corrections, plus/minus branches, signed shifts, missing-child
zeros and every rotation remain in the virtual graph.

Derived source and retained C1 digit states are public recipes in that graph,
with no independently supplied witness or carry choice. Tensor seeds retain
all radix cross terms; unary anchors use the checked source and public key-A
digits; later states require both children. Locally extract seed query digits
from the exact original trusted query. They add no query wire payload and are
not server-selected auxiliary inputs. The public common-integer norm induction
still matters: evaluating that recipe modulo Q alone does not authorize an
arbitrary independent limb lift.

Both full terminal-Q components per group have residual constraints, including
unused coordinates. Thus the relation has exactly `canonical_cuts+2*groups`
residual polynomials. All2,122 residual polynomials in the112 cases were
checked coefficient by coefficient using a separate schoolbook negacyclic
product and signed permutation implementation. No HE evaluator, expected-frame
oracle or private operation is called during relation compilation/checking;
a regression monkeypatches those APIs unavailable. An honest fixture passes,
and altering its first canonical product source or its last physical Q output
coefficient fails independently in every case.

Given truthful source equations, induction fixes every virtual ciphertext and
the final Q outputs for these original inputs/keys. The separate public norm
guards then justify the intended plaintext. This is deterministic full public
residual checking. It does not implement hidden challenges, proof soundness,
one-use attempts, attestation, authoritative compact-frame construction,
private release or durable global limits. The previous compact frames are
retained fixtures; the16 canonical controls match their exact stored frames
