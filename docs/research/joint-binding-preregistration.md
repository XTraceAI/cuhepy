## Question, controls and bounded scope

Can sharing canonical nonlinear cuts and eliminating all intermediate affine
polynomials create a distinct complete verification mechanism? Give an ordinary
linear-expression compiler exactly the same elimination. If its equations,
witnesses and paid costs coincide, stop this literal recipe as a paper claim.
This packet is a relation/count discriminator, not a production verifier,
attestation implementation, public proof, HE parameter approval or latency run.

Implement two explicitly different BGV paths:

1. The actual E73 packed original query, all rotation/decomposition branches,
   fixed encrypted-index products, selected C0 and full C1/C2 wire output.
   No output relinearization or terminal precision conversion is invented.
   Independently compile sparse linear expressions while retaining each global
   integer gadget cut once. Compare to existing E78 public full recomputation
   and E73 GMP evaluation. Use N16, two features, five stable rows including
   duplicate words and ties, all four legal two-bit queries. Every score and
   stable top-three must match independent plaintext ranking and full decryption.
2. A tiny declared two-RNS-limb no-rotation product/relinearization algebra
   fixture, N2, primes17/41, base4. This matches the native path's operations,
   not its N8192/Q120 ABI or approved cryptographic parameters. Compare to
   direct integer negacyclic convolution and literal canonical decomposition.
   A packed-query path followed by output relinearization is NOT silently
   substituted for the actual unswitched E73 output.

## Mandatory falsifiers

Bind original ciphertext, trusted index/key graph, parent epoch/IDs/token and
exact projected wire grammar. Challenge generation is not implemented: exact
residuals precede any abstract field-check counts. Canonical digit bounds and
the globally shared integer representative below Q accompany all field
relations. Remove either deliberately only in a named negative control.

Construct a nonzero digit perturbation in the complete affine relation's
kernel, preserving the honest final output, and force one digit out of range.
The affine-only check must accept this false trace and the canonical check
must reject. Also mutate original C0/C1, context, branch order/count, digits,
global Q aliases, output components, omitted required support and one RNS
limb. Do not equate a correct final answer with an honest internal trace.
Bounded admissible noncanonical protocols such as E81 remain separate known
controls; canonical uniqueness is not claimed universally necessary for HE.

Exhaust all nonzero residual vectors and uniform rows over F5 in dimension3,
including non-basis errors. Count all weights, not Monte Carlo. A public
linked-weight control must expose cancellation. Exhaust a two-attempt aggregate
feedback toy and count its first accepted false trace. These finite algebra
controls do not prove a durable protocol, private timing or 128-bit security.

## Complete cost return

Price canonical source/digit witness bodies, original inputs, projected output,
dense compiled input/cut hints, output challenges, registration and online
scalar work. Canonical digit derivation, index-dependent hint generation and
protected state do not become free after eliminating intermediate nodes.
Compare the source-cut and digit-cut interface with the same representation
given to the generic compiler. Account for each RNS limb and actual limb-word
wire separately from packed integer models. For a point/quotient proposal,
retain E70's degree loss and paid quotient bodies; NTT-root sampling is not a
general field-point check. No GPU timing or cross-study ratio is produced.

Use exact toy results plus bounded count cards for N32/8192,1/2/4 columns,
1/2/128 reply tiles, Q32/Q120 and 4/30-bit digits as labeled models. A real
native, terminal-conversion or full BFV adapter remains open. BFV's tensor
products and integer scale-and-round cuts must not be called affine BGV work.

Advance only if an additional precise mechanism remains after complete
equally optimized controls and can plausibly pass the project's cost screen.
Otherwise record known containment, retain the oracle/counterexample, return
to the plan and proceed to Q28/E102. No broad publication gate is passed by
this bounded negative. The cap is two graph/algebra components and one
exact/count component before native work.
