## The next distinct dependency, not another affine-cap variant

The initial D4 pivot chose **Q31/E105: the full-support nonlinear
carry/dependence discriminator**, now completed below. E102's actual N8/D2 slice varied only two error atoms; it
showed nine rotation-digit tensors but did not compute the full fresh-CBD law.
Seeded first-relin digits do not depend on fresh E; later rotation digits do.
An independent-product MGF cannot be imported past this boundary.

The concrete question is whether one **joint carry-state representation** can
preserve the complete source-plus-maintenance phase law across signed views
and messages with less work/state than an equally optimized generic weighted
aggregation. Tiny exact enumeration is the ground truth, not the contribution.
The generic comparator gets the same cached affine columns, fixed first-relin
work, probability aggregation and canonical arithmetic. State reuse alone or
ordinary dictionary memoization is not novel. If all true states remain
distinct or the control obtains the same saving, stop that literal algorithm.

First freeze one supported setup and an actual uniform mask realization. Keep
the setup diagnostic law separate from honest setup sampling. Enumerate all
3^8 CBD1 value vectors with exact weights over all four legal two-bit messages:
26,244 weighted states, representing 262,144 literal coin outcomes. Preserve
the joint original/rotation/complete phase, every digit tensor and selected
decoder dependencies; independently compare actual search/decode and integer
phase laws. Use rational tails, not fitted Gaussians. A full-domain tiny law
still does not imply a uniform bound across adaptive epochs or 2^-128 tails.

Acceptance needs both a precise new scalable distinction and a plausible
complete consequence. Record setup/mask/coin order, generic containment,
counts, degeneracies and canonical/RNS assumptions. A smaller toy bound is
not a smaller approved modulus, faster native server, security reduction or
production certificate. The initial cap is one joint-law component and one
state/control component; no GPU kernel until a theorem/mechanism survives.
