## 2. Proposed protected check and full-byte binding

After enrolling the immutable approved source/graph/instance/index/key/layout
context, sample an ideal secret uniform `r in F_ell^368` and privately compute
`h=A_aff^T*r`. Store h with its exact column order. This preparation is trusted;
accepting a host-supplied h or replacement A would defeat the check. r may be
discarded after correct preparation; h must remain protected.

For one request, the checker would:

1. Pin the owner-original query, the complete response, request identifier,
   context/instance/source/encoding digests and epoch. Parse all original packet
   metadata and coefficient grammar, including every unused response position,
   and require the declared complete canonical serialization.
2. Admit exactly4,096 bytes as a declared32,768-bit little-endian tape. Its
   first28,879 bits are w; all remaining3,889 bits must be zero. Each admitted
   witness coordinate is then exactly0 or1. Use one stable byte snapshot for
   parsing, checking, hashing and signing to avoid host buffer substitution.
3. Independently expand the ORIGINAL query and derive all256 public values u
   from that query and ALL response coefficients. No host-declared RHS, field
   value, layout, domain or instance is trusted.
4. Check `h_w*w + h_constant + h_u*u = 0 mod ell`. The bit/range/no-wrap and
   terminal relation is the complete E108 control; the row aggregation does
   not remove any of those obligations.
5. Authenticate the complete same statement/response only after admission and
   this check. The client checks actual attestation/receipt and independent
   original-request/enrollment pins, consumes its durable one-use state, and
   invokes private decryption only after acceptance.

The logical h needs29,136 field words. Backend-style padded columns instead
move the constant/public positions after32,768 witness slots; naively appending
zeros to the old z while retaining old column numbers is incorrect. This card
uses the logical h and separately checks/discards the zero padding. It does
not instantiate Spartan's padded oracle or depend on its PCS API.

This protocol does not give the protected checker HE secrets or plaintext.
It needs private checking state and attestation credentials. Hosting the full
plaintext index in a TEE is a distinct, permitted stronger-trust control.

## 3. Exact conditional repeated-attempt argument

For any fixed nonzero field residual `v=A_aff*z`, ideal uniform r satisfies
`Pr[r^T*v=0]=1/ell`. For reuse, conditioning r on actual prior rejection bits
and calling it still uniform is invalid. Use the FIRST-false-accept argument:

* Fix the adversary's coins, the enrolled context and public/owner randomness
  that is independent of r. Define an ideal checker that accepts every zero
  residual and rejects every nonzero residual, while applying the same grammar
  and domain checks. Until the first false acceptance, actual and ideal public
  interactions coincide.
* On this ideal all-invalid-rejections branch, the successive submitted
  nonzero residuals are fixed independently of r. Valid submissions always
  succeed independently of r. Thus each possible first false acceptance is
  contained in one of at most T events `r^T*v_i=0`; union bound them.

This proves only the unconditional ideal-checker bound

```
Pr[at least one false relation acceptance within T attempted submissions]
 <= T/ell.
```

The one frozen illustrative T=2^32 gives the exact rational

```
4294967296 /
7237005577332262213973186563042994240857116359379907606001950938285454250989
< 2^-220.
```

This is not220-bit deployed security or correctness conditioned on receiving a
response. A malicious host can submit only on rare events. The argument requires
that **nothing about r/h leaks beyond the modeled verdicts**: no dot value,
partial row result, secret-dependent time, page/cache/access trace, host-readable
state or deterministic digest of r/h. A published hash of private checking state
is not information-theoretically innocuous; any such interface needs a separate
computational leakage argument. Existing variable-time GMP/Python arithmetic is
not a reviewed implementation of this private check.

Source/index/key/layout changes invalidate h and require a fresh independent
checker epoch after enrollment. Count every attempted submission, retry,
abandoned request and crash conservatively. Durable state must prevent rollback,
snapshot cloning or counter resets from creating uncounted attempts; a request
nonce alone is not a lifetime counter. Concurrent attempts must share that
atomic budget and bind the same immutable state. Across multiple fresh epochs,
sum `T_epoch/ell`, not one single-epoch bound. Entropy, setup/admission,
attestation/signature forgery, state rollback, implementation leakage and any
computational randomness transfer have separate unassigned terms.

This ordinary argument supplies no HE confidentiality or malicious-server
feedback-security reduction. Q41's codec/secret correctness event and the
complete original-query-to-response relation must still compose under their
actual assumptions. No sampler, field challenge or lifecycle was implemented.

remote client also needs the tape rather than just a trusted complete-statement

the tape on the server, but that does not make host-to-checker upload, parsing
or receipt bytes vanish. Evidence sizes above cannot be compared as a complete
WAN or latency win before this topology and actual attestation are fixed.

For this tiny relation, dense h plus declared maps is967,936 B before metadata,
where full encrypted-index/key bodies are4,080 B. The padded evidence also adds

fewer trusted affine terms do not establish an end-to-end benefit or a scaling
result. E109's larger proof is not a lower bound on BitZ/ring/lookup alternatives.
