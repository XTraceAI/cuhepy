## Precise candidate and originality obligation

For an incomplete first group, the first butterfly stage can be entirely unary:
`m <= D/2`. Its automorphed switching source alone then determines the prior
C1 polynomial. Starting with its small common radix digits, propagate a
noncanonical integer gadget representation into the next stage through
decomposed *public* key-A polynomials. This may remove a later nonlinear
source/witness cut without adding the otherwise necessary plus-branch witness.
The new switch digits are larger; charge their worst-case noise, full terminal
guard, extra public products/state, and any higher output precision.

For `G=(1,B,...,B^(ell-1))`, let `G*d=z` modulo Q. With a unary rotation g,
its output C1 is `sigma_g^-1(z) + sum_a d_a*K_A[a]`. Write public canonical
key digits `K_A[a]=sum_j B^j*A[a,j]`. A valid integer representation is

`E_j = sigma_g^-1(d_j) + sum_a d_a * A[a,j]`.

At the next stage h, including an actual binary right branch shifted by M,
the source digits are `delta_j=sigma_h(E_left[j]-M E_right[j])`. They recompose
to the correct source modulo Q but need not be canonical. Their exact integer
norm bound must hold for every admitted small source, independently of private
error observations. Terminal rounding and the full physical response remain
bound to the new evaluator. Ciphertext-byte equality to the old evaluator is
not the contract: plaintext scores/IDs must agree, while a malicious tape must
still satisfy the complete new relation before private decoding.

This propagation algebra may be known. Homomorphic gadget decomposition,
bounded relaxed maintenance, delayed key switching, bivariate representations,
public composite-key precomputation and generic affine checking are mandatory
controls. The proposed research question is whether the *packing-dependent
unary anchor*, its noise-safe cut placement, and a complete verification
implementation yield a useful, prior-separated systems/algorithm result.
No original primitive, secure protocol, or performance win is asserted here.
Do not declare novelty merely because a canonical-only compiler lacks this
semantic rewrite; give the strongest compatible published gadget methods an
explicit adaptation opportunity.

## Expected falsifiers and complete cost

For an integer digit state bounded by L, the unary update bound is
`L*(1+ell*N*(B-1))`. A following binary source has bound at most twice that.
Propagated digits may exceed one RNS prime; interpreting an arbitrary residue
as a small signed integer would be unsound. Use one proven common integer
representation or a derived affine map, not independently chosen limb digits.
Repeated unnormalized propagation is expected to blow up quickly; a third
stage is a registered negative/control, not permission to raise production Q.

For full groups the first minus source cannot determine its plus source.
Register the extra witness required to repair that loss and charge it. A
counterexample to a minus-only anchor in a full binary group is required.
Small partial groups must not be used to claim all-size savings.

Direct propagation can add ell-squared ring products per node. A fused known
control may precompute `sum_j sigma_h(A[a,j])*K_next[j,k]` and use the same
derived state. Include that control; its setup and memory are not free.
Input digit-box checks and terminal conversion remain explicit. Compare actual
complete witness paths separately from the earlier product-only128MiB/trusted
suffix path; eliminating a rotation cut does not remove a transmitted product
body automatically.

A semantic correctness argument is only one prerequisite for malicious-server
privacy. The complete relation, immutable query/snapshot/epoch, hidden challenges,
response binding, honest phase bounds, global attempts and protected execution
still need the reviewed composition. This cycle does not expose production
secrets or modify production fallback code.
