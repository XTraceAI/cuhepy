# E31: hierarchical query intersections and CRT geometry

2026-09-29. Homemade finite-field algebra, GMP BGV and the existing homemade
C++ short-subring evaluator. Benchmark source:
`80f3cc469e3c44efa5bdf92dd87e43af7b21cbba`. The
[E30 baseline](shared-query-basis-results.md) is preserved at `d24ad5f` and
`checkpoint/shared-query-basis-2026-09-29-final`.

**Result:** exact direction sharing reduces query bodies substantially while
keeping the local encrypted index at 5,242,880 bytes. It does not improve
end-to-end speed or total owner state in these experiments. Most query savings
already come from merging identical basis rows. The hierarchy improves the
correction-degree budget; regrouping improves query size further but can worsen
that budget. These are useful distinct objectives, not a universal speedup.

## Hypothesis and implementation

E30's arbitrary global common space could increase the number of encrypted
columns. E31 instead extracts directions that actually lie in every descendant
block's row space. Let `U_l` be a leaf's private affine direction space and
`I_v = intersection_{l below v} U_l`. Recursively choose a basis of `I_v`
modulo the directions already assigned to ancestors. A leaf's coordinates
then reconstruct its row exactly:

```
x = a_l + sum_{v on root-to-leaf path} c_v B_v   (mod t)
H(q,x) = H(q,a_l) + sum_v c_v [B_v(1-2q)]        (mod t).
```

The triangular enrollment solve subtracts each ancestor's contribution before
reading the next node's pivots. Every enrolled row is certified. Each leaf
retains its original rank, so `F=max leaf rank` is unchanged (with a zero dummy
feature for constant leaves). Disjoint subtrees reuse encrypted columns.
Private directions that are exactly equal also reuse a query coordinate,
including across disconnected subtrees; that equality schedule is public.

For each column, recursively merge CRT siblings only if they name the same
masked variable or are both unused. If the deepest remaining node has depth
`d_j`, the correction lies in the degree-`S_j=2^d_j` subring generated by
`X^(N/S_j)`. The full encryption ring and secret still have degree `N`.
The number of correction coefficients and hidden shift fingerprints is
`W=sum_j S_j`. The implementation derives this degree from IDs, never from
accidental equality of one request's values.

The exact intersection implementation solves `u*(A mod B)=0` over `F_t`, then
forms `u*A`. It finds the E30 missed-intersection example `(1,3,4)` over `F_7`.
There is no floating-point rank estimate, approximate search or imported HE
implementation. The existing evaluator/checker already support separate groups
of columns by subring degree; E31 exercises intermediate degrees as well as
the previous scalar/full-short-ring endpoints. No C++ source was changed.

## A restricted optimality check

For a **fixed binary tree**, require each node's directions to lie in every
descendant space, exact leaf ranks, and no sharing between disconnected nodes.
Let `a_v` be the cumulative number of independent directions assigned from the
root through node `v`, and let `r_l=dim U_l`. The number of node coordinates is

```
H = sum_leaves r_l - sum_internal_nodes a_v
  >= sum_leaves r_l - sum_internal_nodes dim I_v.
```

This identity follows by counting each assigned node direction once along the
binary tree. Since `I_parent` is contained in `I_child`, complements can attain
all `a_v=dim I_v` simultaneously. Full recursive intersection extraction
therefore minimizes **this laminar coordinate count**. The argument does not
optimize byte encodings, tree selection, column-degree sum, or representations
that expand leaf ranks. Exact-row merging between disconnected nodes can
reduce the actual query count `h` below this restricted `H`.

The tests independently enumerate all subspace point sets in `F_5^2` and all
64 ordered pairs. A four-leaf oracle checks 625 input-space tuples from a
five-space catalog in `F_17^2`, considering all 20 possible common subspaces
at internal nodes. A separate four-leaf grouping example checks all 24 leaf
permutations. These are small exact controls, not a proof of greedy grouping
optimality on the real datasets.

There is also a simple representation bound: `h <= W`. For each column,
its distinct variable IDs must inject into its `S_j`-dimensional correction
space, and every declared coordinate appears in some column. At the current
deterministic phase bound, the 32-bit profile permits at most `W=150` for
`N=16384,t=1153,eta=21`. The regrouped `h=164/173` alone therefore prevents
reaching that threshold by column alignment alone, under this bound.

## Controls and measurement scope

Two pinned Mushroom splits, seeds 3001/3002: 7,996 distinct enrolled rows,
126 bits, 128 held out. The same one warmup plus three measured held-out
queries used in E29/E30 are reused here. Eight variants per split give
**64 complete encrypted searches**, but only eight distinct held-out queries.
Every score and stable top-three result matches direct plaintext Hamming
distance. GMP/native ciphertext coefficients, context and bounds agree.
The conditional fingerprint check occurs before HE decryption.

All local variants use `N=16384,t=1153,eta=21`, 32 encrypted columns, one
response, `Q=1099510054913` and four checking rounds. Global affine and raw
controls use `Q=4294475777` and five rounds, as in E30. A modulus choice is a
correctness calculation, not a reviewed security estimate. Full-Q responses
are returned; there is no terminal compaction. No CUDA or SEAL timings were
added. These are small CPU diagnostic samples, not p95 or significance claims.

The index-only sharing-depth curve includes leaf-only exact-row merging,
root intersection, and successively deeper internal sharing. A state selector
charges private maps, checker hints and actual canonical public-space JSON;
it selects root-only for split 3001 and leaf-only for split 3002. It sees no
future query or measured latency. We also retain two geometry controls:

- **Uniform hierarchy:** split coalesced leaves into equal-capacity slots,
  preserving all row memberships and the response budget.
- **Regrouped hierarchy:** greedily pair equal-capacity clusters by their exact
  common-space rank, with deterministic ties. This is a bounded heuristic,
  not optimal matching. Its 0.61/0.69 s grouping cost is recorded separately.

Fresh HE keys, encryption errors and checker randomness use OS randomness.
Mask seeds from the benchmark PRNG are public reproducible fixtures, never
deployment secrets. Exact-form IDs add equality leakage; maps/anchors remain
private. The full declared coordinate space is masked, including dummy forms.
Independent uniform masks are the idealized model; seeded SHAKE expansion
requires its own pseudorandomness assumption in the complete protocol.

The native backend already uses small NTTs. It still visits all 32 full-sized
encrypted columns, and intermediate degrees require several native handle
calls and full reply-buffer passes. GMP still performs full-ring products for

These observations explain why this algebraic reduction is not an end-to-end
speedup. Isolating each overhead or changing the native ABI would require a
separate ablation; the small timing differences alone do not prove causality.

## Protocol obligations and prior work

The [authenticated-correlation contract](authenticated-correlation-contract.md)
now specifies mask/output/checking functionality, party knowledge, both fields,
malicious setup, collusion, updates, expiry and crash-safe consumption.
It is a research specification, not an implemented PCG or durable service.
The conditional checker still requires trusted index and token preparation.
Whole-client private arithmetic, lattice parameters and the complete protocol
remain unreviewed. E31 is not a production authentication upgrade.

Hierarchical sharing is established prior work. We read the abstract and
Sections 1–2.2 of [Yi, Wong and Gaynanova, *Hierarchical nuclear norm penalization
for multi-view data integration*](https://onlinelibrary.wiley.com/doi/full/10.1111/biom.13893).
It defines partially shared structures recursively after accounting for earlier
levels, with a statistical real-valued estimation objective. Our exact finite-field
CRT schedule has different constraints; that difference alone establishes no
novelty. No code from that work was imported. E30's JIVE/Oraqle precedents and
the older CRT/NTT/fingerprinting precedents still apply.

## More promising next experiment: the phase bound itself

The deterministic `L1` bound charges maximum error in every coefficient with
the worst possible sign simultaneously. Our symmetric ciphertexts have exact
fresh phase `m+t*e`, with independently sampled centered-binomial `CBD(eta)`
errors. This suggests a different experiment rather than assuming further
hierarchy tuning will shrink the large response.

For fixed corrections independent of encryption errors, one coefficient's
random error has variance proxy
`t^2 * eta/2 * (1 + sum_j ||alpha_j||_2^2)`. This follows from
`E exp(lambda*e) = cosh(lambda/2)^(2*eta) <= exp(eta*lambda^2/4)` and independent
fresh error coefficients. The deterministic message/carry contribution is at
most `b*(1+W*b)`, with `b=floor(t/2)`; it must not be dropped.

For `B` queries and `R` replies, a union-bound candidate is

```
|phase| <= b*(1+W*b)
           + t*sqrt(eta*(1+W*b^2)*ln(2*N*R*B/epsilon)).
```

The summarizer rounds this upward using integer arithmetic and the conservative
`ln(2)*k < 0.7*k`. For `B=1024,epsilon=2^-128`, it projects:

| Original local case | Current deterministic bound | Prospective total bound | q32 half modulus |
|---|---:|---:|---:|
| Mushroom, W=1024 | 14,621,171,925 | 1,350,901,334 | 2,147,237,888.5 |
| Semeion, W=1472 | 21,017,923,797 | 1,700,715,656 | 2,147,237,888.5 |

This is an **unimplemented correctness hypothesis**, not a security-level
claim or evidence from q32 encrypted searches. No key-generation gate or
deterministic phase-bound metadata was relaxed. The argument needs independent
review, exact-phase experiments, error-dependent negative controls, and a
lifetime/adaptivity analysis for seeded masks and reused encrypted columns.
Sampling a few successful decryptions cannot validate a `2^-128` bound.
Adversarially error-dependent corrections do not inherit the independence
assumption. Public-key encryption, ciphertext products, rounding and other
noise distributions also require different analyses.

If justified, a q40-to-q32 change would reduce full coefficient bodies by 20%
even for the original local representation, addressing the response/index
directly. This is a more discriminating next experiment than claiming the
0.4–0.5% online-byte reduction already solves IO. Retain E31 as an independent
representation option and the original deterministic profiles as controls.
