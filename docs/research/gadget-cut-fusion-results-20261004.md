The [C++ kernel](../../experiments/bfv_search_lab/_gadget/noise_cut_kernel.cpp)
uses the repository's own `PrimeNTT` and GMP. It links no SEAL. Both native

The kernel checks **every NTT coordinate in both actual prime limbs**.
Invertibility makes this deterministic full polynomial equality, with no
hidden challenge, scalar one-point shortcut or statistical acceptance error.
It independently evaluates the complete compiled relation; HE replay,
expected-response and private APIs are unavailable in a regression.

Two fresh homemade RNS keys at N16/N32, two queries each and four geometries
produce 16 geometry/query pairs and 32 canonical/variant relations. Honest full
Q/P plaintext coordinates, distances, stable IDs and top3 agree. Native direct,
native fused and independent schoolbook vectors agree in both actual primes
on all honest and 64 changed tapes. This is a **new small correctness cohort**;
the previous single 120-bit-prime keys cannot be reinterpreted as these RNS keys.

The second component reuses those 32 relations. Its fixed-slot body is exactly
`15*N*(canonical_sources+2*groups)` bytes. The native parser validates **every**
common-Q coefficient and complete length before arithmetic, then derives
canonical30 digits from that same integer on demand. The owner query is copied
at enrollment and is absent from the server body. This avoids the first
adapter's whole digit/RNS binding buffer. All 64 changed tapes and 96 malformed
length/last-range bodies reject. Tests also reject one-limb forgeries and a
nonzero polynomial that vanishes at one NTT coordinate. Immutable handle copies
preserve ownership, serialization is prohibited and wrong-process use rejects.

The small enrollment adapter still uses a Python coefficient-preparation oracle
and enforces N<=128. Actual native root/map/STL/allocation state is additional
to the arithmetic tables in the model. There is no complete request/epoch/ID
header, one-use network controller, authoritative terminal-frame release,
attestation or private callback. The code is a public experimental component,
not production authorization. [Conditional assurance and remaining interfaces](gadget-cut-native-kernel-assurance-20261004.md)
separate the algebra from those unfinished obligations.
